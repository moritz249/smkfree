Installieren

Auf den Home-Bildschirm

iPhone / iPad

  1. Öffne SMKFREE in Safari
  2. Tippe unten auf Teilen ⬆
  3. Tippe auf Zum Home-Bildschirm
  4. Tippe auf Hinzufügen

Android

  1. Öffne SMKFREE in Chrome
  2. Tippe oben rechts auf ⋮
  3. Tippe auf Zum Startbildschirm hinzufügen
  4. Tippe auf Hinzufügen

Computer (Chrome / Edge)

  1. Öffne SMKFREE in Chrome oder Edge
  2. Klicke in der Adressleiste auf das Installieren-Symbol ⊕
  3. Klicke auf Installieren

Install

Add to your home screen

iPhone / iPad

  1. Open SMKFREE in Safari
  2. Tap the Share icon ⬆ at the bottom of the screen
  3. Tap Add to Home Screen
  4. Tap Add

Android

  1. Open SMKFREE in Chrome
  2. Tap ⋮ in the top right corner
  3. Tap Add to Home screen
  4. Tap Add

Desktop (Chrome / Edge)

  1. Open SMKFREE in Chrome or Edge
  2. Click the install icon ⊕ in the address bar
  3. Click Install
